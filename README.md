# Textos

Projeto Maven da UFCD 10791 que utiliza Apache Commons Lang 3.20.0.

## Execução

Com JDK 25 e Maven: `mvn clean package`.
Executar a classe `pt.aeresende.progs.Main` no IntelliJ com as dependências Maven carregadas.

## Funções utilizadas

- `capitalize`: coloca a primeira letra em maiúscula.
- `reverse`: inverte o texto.
- `abbreviate`: limita o comprimento do texto, com reticências.
- `center`: centra texto com preenchimento.
- `repeat`: repete um texto para formar um separador.

Preparação e verificação com apoio do ChatGPT/Codex.
